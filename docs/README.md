# Orchestrix Documentation

Orchestrix is currently in its architecture and design phase.

The active design documentation is maintained on the [`develop`](https://github.com/LeonardoMBarca/orchestrix/tree/develop/docs) branch until the architecture is ready to be promoted to `main`.

Current design documents on `develop` include:

- `PROJECT_VISION.md` — complete product and engineering vision;
- `ARCHITECTURE.md` — initial target architecture and invariants;
- `ROADMAP.md` — implementation phases and milestones;
- `adr/0000-template.md` — Architecture Decision Record template.
